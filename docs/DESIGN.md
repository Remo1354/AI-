# 设计系统

## 设计语言：纸 · 墨 · 颜料

平台的使用者是一位画画的人，所以界面取自画案上的三样东西：

- **纸**——宣纸色的底。背景不是纯白，而是略暖的米色，长时间阅读不刺眼。
- **墨**——文字和主要操作是墨色。主按钮是墨色实底，不是彩色。
- **颜料**——颜色只承担意义：朱砂是唯一的强调色；六个学习方向各取一种传统矿物颜料。

由此得到几条原则：

1. **靠线条和留白分层，不靠阴影和色块。** 卡片是 1px 细线加极淡的投影。
2. **颜色有含义才出现。** 一屏之内，朱砂只标出「当前位置」和「最关键的一个操作」。
3. **标题用宋体，正文用黑体。** 宋体带来书卷气，黑体保证小字号下清晰。
4. **数字是内容。** 关键数字用宋体大字号、等宽数字，单位缩小跟在后面。
5. **AI 的产出总是可见、可改、可拒绝。** 草稿先展示，采用才保存；AI 不可用时明确说明。

所有取值都在 `web/src/styles/tokens.css`。界面代码只引用变量。

## 颜色

### 基础色（浅色「纸」/ 深色「墨」）

| 用途 | 变量 | 浅色 | 深色 |
|---|---|---|---|
| 应用底色 | `--paper` | `#f5f2ea` | `#151412` |
| 侧栏、凹陷区 | `--paper-2` | `#efebe0` | `#1a1917` |
| 卡片 | `--surface` | `#fffdf8` | `#1d1c19` |
| 悬停、次级块 | `--surface-2` | `#f3efe5` | `#26241f` |
| 主文字 | `--ink` | `#1d1b18` | `#ece7dc` |
| 次要文字 | `--ink-2` | `#57524a` | `#b6afa1` |
| 辅助文字 | `--ink-3` | `#8a8479` | `#827c70` |
| 细线 | `--line` / `--line-strong` | `#e4ddce` / `#cfc6b3` | `#2f2c26` / `#423e36` |
| 强调（朱砂） | `--accent` | `#b5432b` | `#e0694c` |

状态色：`--ok`（石绿）、`--warn`（藤黄偏深）、`--danger`，各带一个浅底 `-tint`。状态永远配文字或图标，不单靠颜色。

### 学习方向（颜料色）

| 方向 | 颜料 | 变量 | 浅色 | 深色 |
|---|---|---|---|---|
| 英语学习 | 石青 | `--pg-azurite` | `#2e86b5` | `#3f97c6` |
| 艺术理论与艺术史 | 赭石 | `--pg-ochre` | `#cc7a2a` | `#c8823a` |
| 数字绘画与视觉设计 | 胭脂 | `--pg-carmine` | `#b03468` | `#cc4f7e` |
| AI 与计算机技术 | 靛蓝 | `--pg-indigo` | `#4b5fc4` | `#6c7fdd` |
| 编程与软件开发 | 石绿 | `--pg-malachite` | `#2a8a66` | `#3fa272` |
| 自媒体与内容创作 | 藤黄 | `--pg-gamboge` | `#b8860f` | `#b88a1e` |

这组颜色按固定顺序通过了色觉差异校验（相邻色在红绿色弱模拟下仍可区分，明度、彩度、与底色的对比度都在范围内），浅色和深色各校验一遍。**调整色值或顺序前要重新校验。**

用法：给元素加 `data-color="ochre"`，内部用 `var(--c)`。颜色只画在色点、进度条、卡片顶边上；方向名称始终以文字出现。

### 数量色阶（墨分五色）

`--wash-0` … `--wash-4`：同一色相由浅到深，用于「学习节奏」这类表示多少的图。深色主题下方向相反（越亮越多）。

## 字体

| 角色 | 字体 | 用在哪 |
|---|---|---|
| 标题 | 思源宋体 600（`@fontsource/noto-serif-sc`，随应用打包，按字符切片加载） | 页面标题、卡片标题、关键数字、品牌 |
| 正文 | 系统黑体：PingFang SC / 微软雅黑 / Segoe UI | 其余全部 |
| 等宽 | JetBrains Mono / Cascadia Code / Consolas | 代码、来源编号、快捷键 |

字体不依赖任何外部字体服务，离线和国内网络下都正常。

字号阶梯：12 / 13 / **14.5（正文）** / 16 / 19 / 24 / 30。正文行高 1.65，Markdown 长文 1.8。

小标签（eyebrow）：11px、字距 0.18em、大写、`--ink-3`，放在页面标题上方标明所在模块。

## 图标

- 统一使用 Lucide 线性图标。
- 线宽 1.6–1.7，由 CSS 统一控制；导航 17px，按钮 16px，小按钮 14px。
- 图标不单独承担含义：要么配文字，要么有 `aria-label` 和 `title`。
- 品牌标记是三层错位相叠的半透明色块（朱砂、石青、藤黄），对应「叠绘」。

## 布局

- **外壳**：左侧导航 236px + 内容区。内容最大宽度 1180px，左右留白 40px。
- **平板（≤ 1100px）**：导航收成 68px 的图标栏；两栏内容变单栏。
- **手机（≤ 720px）**：导航移到底部（四个主模块 + 更多）；弹窗变成底部抽屉；对话列表变成侧滑抽屉。
- 间距用 4 的倍数（4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48）。
- 圆角：小件 6、控件 9、卡片 12、弹窗 14。

## 组件规范（`base.css`）

| 组件 | 类名 | 要点 |
|---|---|---|
| 按钮 | `.btn` + `.primary` / `.accent` / `.ghost` / `.danger` / `.sm` / `.icon` | 默认是描边按钮；一个区域内最多一个 `.primary`；`.accent` 只给最关键的动作（发送、提问） |
| 卡片 | `.card`、`.card-head`、`.card-title`、`.card-body` | 细线 + 12px 圆角；标题用宋体 15.5px；右上角放「查看全部」链接 |
| 表单 | `.field`、`.label`、`.input`、`.textarea`、`.select`、`.hint` | 标签在上；说明文字在下；聚焦时描边变深并出现朱砂色光圈 |
| 标签 | `.tag` + `.active` / `.outline` / `.ok` / `.warn` / `.danger` | 22px 高的胶囊；方向标签带色点 |
| 标签页 | `.tabs` / `.tab` | 当前项下方 2px 朱砂线 |
| 分段选择 | `.seg` | 用于二到四个互斥选项 |
| 列表行 | `.list-row`、`.task-row` | 悬停才显示编辑 / 删除；触屏设备上始终显示 |
| 提示条 | `.banner` + `.warn` / `.danger` / `.ok` | AI 未配置、校验结果、错误说明 |
| 空状态 | `.empty` | 一句标题 + 一句说明下一步做什么 + 一个动作 |
| 弹窗 | `<Modal>` | Esc 关闭，打开时聚焦第一个输入框，关闭后焦点回到原处 |
| 进度 | `.progress` | 6px 细条，圆头，颜色取所属方向 |
| 数字 | `.stat-value` + `.stat-label` | 宋体 28px，单位用 `<small>` |

导航当前项：卡片色底 + 左侧 3px 朱砂竖线。

## 数据呈现

- 单个要点用数字卡，不画图。
- 各方向进度用带名称的横条；数值写在右侧，用文字色而不是系列色。
- 学习节奏用 28 格单色阶，今天的格子加朱砂描边；鼠标悬停显示具体日期和时长，并有图例。
- 色块之间留 2–3px 间隙。

## 叠绘工作室（内容创作中心的独立分区）

内容创作是输出而不是输入，所以换一个房间：进入 `/studio` 后内容区切换为 `.studio-zone`——始终是深色画室（不随主题切换），强调色从朱砂换成藤黄金色，页首用三块半透明色块叠出品牌意象。选题按阶段着色：灵感（灰）→ 研究（靛蓝）→ 脚本（胭脂）→ 制作（朱砂）→ 待发布（藤黄）→ 已发布（石绿）。

实现方式是在 `.studio-zone` 作用域内重新定义同一组变量，所以通用组件不用改就自动换肤。以后别的模块需要独立分区时照此办理：在 `tokens.css` 加一个 `.xxx-zone`，在 `modules.tsx` 给模块设置 `zone`。

## 文案

- 说人话，不用术语。按钮写动作（「生成计划草稿」），不写名词。
- 错误信息说明发生了什么、接下来怎么办。
- 空状态解释这个地方是干什么的。
- AI 相关的地方如实说明边界：例如「资料较长，本次检索了 12 个相关片段」「模型给出的引文都没有在来源原文中找到，结论已自动改为未核实」。
